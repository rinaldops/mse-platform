# com_categories — Categorias (reservado)

Pasta reservada para o componente `com_categories` (Categorias) do
Administrator, seguindo a convenção de diretórios do Joomla!
(`components/com_xxx/`).

Achado do levantamento em `docs/JOOMLA-CONVENCOES-E-MIGRACAO.md` (seção de
inventário): o mse-platform ainda não implementa categorias como entidade
própria — conteúdo (`com_content`) usa um campo de texto livre de
categoria, sem taxonomia dedicada. Esta pasta existe apenas para manter a
enumeração de componentes administrativos completa e honesta; **não há
implementação nova nesta rodada**, apenas a reserva do nome/local físico
para quando essa funcionalidade for priorizada.
