# com_tags — Tags

Componente `com_tags` (Tags) do Administrator, seguindo a convenção de
diretórios do Joomla! (`components/com_xxx/`). Sustentado pela lista
`MSETags` (`kernel/schemas/mse-tags.js`, ≈ Joomla! `#__tags`) — CRUD-lite
completo (criar/editar/excluir/publicar/despublicar), mesmo padrão de
`components/com_modules`.

Ver `tags-editor.js` (validação e tela de listagem/formulário) e
`tags-screen.js` (wrapper montado por `components/com_cpanel/component.js`
em `option=com_tags`).
