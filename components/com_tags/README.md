# com_tags — Tags (reservado)

Pasta reservada para o componente `com_tags` (Tags) do Administrator,
seguindo a convenção de diretórios do Joomla! (`components/com_xxx/`).

Achado do levantamento em `docs/JOOMLA-CONVENCOES-E-MIGRACAO.md` (seção de
inventário): o mse-platform ainda não implementa tags como entidade
própria. Esta pasta existe apenas para manter a enumeração de componentes
administrativos completa e honesta; **não há implementação nova nesta
rodada**, apenas a reserva do nome/local físico para quando essa
funcionalidade for priorizada.
