# com_media — Mídia (reservado)

Pasta reservada para o componente `com_media` (Gerenciador de mídia) do
Administrator, seguindo a convenção de diretórios do Joomla!
(`components/com_xxx/`).

Achado do levantamento em `docs/JOOMLA-CONVENCOES-E-MIGRACAO.md` (seção de
inventário): o mse-platform ainda não implementa um gerenciador de mídia
próprio (imagens/arquivos ficam na biblioteca de documentos nativa do
SharePoint, fora deste componente). Esta pasta existe apenas para manter a
enumeração de componentes administrativos completa e honesta; **não há
implementação nova nesta rodada**, apenas a reserva do nome/local físico
para quando essa funcionalidade for priorizada.
